# Phishing URL Detector 🔐

## 🌐 Live Demo

🚀 [Try the Phishing URL Detector](https://phishing-url-detector-cdgv.onrender.com)

A machine-learning-based web application that analyzes a URL and predicts whether it is **legitimate or potentially phishing**.

The project extracts features from a URL, uses a trained machine-learning model to classify it, and displays the prediction through a simple web interface.

> **Disclaimer:** This project is for educational and research purposes. A prediction from this tool should not be treated as a guarantee that a URL is safe or malicious.

## 🚀 Features

* 🔎 Analyze URLs for phishing-related characteristics
* 🤖 Machine-learning-based URL classification
* 🌐 Simple web interface for entering a URL
* 📊 URL feature extraction
* 📈 Model performance reporting
* ⚡ Local Flask web application
* 🛡️ Helps demonstrate common characteristics associated with suspicious URLs

## 🧠 How It Works

The application follows this basic workflow:

```text
User enters URL
       ↓
URL feature extraction
       ↓
Machine-learning model
       ↓
Prediction
       ↓
Legitimate / Phishing
```

The model analyzes characteristics of the URL, such as URL length and other URL-related features, before generating a prediction.

## 📊 Model Performance

The model was trained using a dataset containing **2,488 samples** and **13 input features**.

### Test Results

| Metric            |     Result |
| ----------------- | ---------: |
| Accuracy          | **88.55%** |
| Test Samples      |        498 |
| Class 0 Precision |       0.89 |
| Class 0 Recall    |       0.90 |
| Class 0 F1-score  |       0.90 |
| Class 1 Precision |       0.88 |
| Class 1 Recall    |       0.87 |
| Class 1 F1-score  |       0.87 |

The reported accuracy is based on the current training/testing setup in `train_model.py`.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/gapatshivam1-dev/phishing-url-detector.git
cd phishing-url-detector
```

### 2. Create a virtual environment

Windows:

```powershell
python -m venv venv
```

Activate it:

```powershell
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Train the model

```bash
python train_model.py
```

This generates the trained model locally.

### 5. Start the web application

```bash
python app.py
```

Then open the local address shown by Flask in your browser.

## 🌐 Using the Application

1. Start the Flask application.
2. Open the web page in your browser.
3. Enter or paste a URL.
4. Submit the URL.
5. The application extracts URL features.
6. The trained model predicts whether the URL is potentially phishing or legitimate.

## ⚠️ Limitations

* Machine-learning predictions are not always correct.
* The current model achieves **88.55% accuracy** on the reported test set, so false positives and false negatives are possible.
* The model depends on the quality and diversity of its training data.
* A URL that appears legitimate to the model may still be dangerous.
* New phishing techniques may not be represented in the training dataset.
* The application should not be used as the only security mechanism for deciding whether to visit a website.
